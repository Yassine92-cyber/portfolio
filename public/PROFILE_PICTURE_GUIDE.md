# Profile Picture Setup

## Quick Setup

To see your profile picture in the hero section, add your image to:

**Location:** `public/profile.jpg`

## Supported File Names
- `profile.jpg` (recommended)
- `profile.jpeg`
- `profile.png`
- `profile.webp`

## Recommended Specifications
- **Size:** 400x400px or larger (square aspect ratio works best)
- **Format:** JPG, PNG, or WebP
- **Quality:** High quality for best appearance

## After Adding

1. Save your image as `profile.jpg` in the `public/` folder
2. Refresh your browser
3. The profile picture will appear in the top-right corner of the hero section

## Current Status

If you don't see your picture, it means the file hasn't been added yet. The component will show your initials "YK" as a placeholder until the image is added.

## Troubleshooting

**If the picture doesn't appear:**
1. Check the file name is exactly `profile.jpg` (case-sensitive)
2. Verify the file is in the `public/` folder (not a subfolder)
3. Make sure the file extension is correct (.jpg, .jpeg, .png, or .webp)
4. Try refreshing the browser (Ctrl+Shift+R or Cmd+Shift+R)
5. Check the browser console for any errors
