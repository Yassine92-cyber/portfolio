# Organization Logos

Add your organization logo images here. The component will automatically use them, or fall back to text if images are not found.

## Required Logo Files:

- `slush.png` - Slush logo
- `junction.png` - Junction logo
- `arctic15.png` - Arctic15 logo
- `helsinki.png` - University of Helsinki logo
- `espoo.png` - City of Espoo logo
- `haaga-helia.png` - Haaga-Helia logo
- `familia.png` - Familia logo
- `think-africa.png` - Think Africa logo

## Recommended Specifications:

- **Format**: PNG with transparent background (preferred) or SVG
- **Size**: 200-300px width, maintain aspect ratio
- **Style**: 
  - White/light logos work best on the light background
  - Logos will be displayed in grayscale by default, full color on hover
- **Naming**: Use exact filenames as listed above (case-sensitive)

## Fallback:

If a logo image is not found, the component will automatically display the organization name as text in a bordered box.

## Tips:

- Use logos with transparent backgrounds for best results
- Ensure logos are high quality and readable at small sizes
- Test logos on both light and hover states (grayscale vs full color)
