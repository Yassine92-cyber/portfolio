# Blog Thumbnails Guide

## 📁 Folder Location
All blog thumbnail images should be placed in this folder: `public/blog-thumbnails/`

## 🖼️ Image Requirements

### Recommended Specifications:
- **Size:** 800x600px (4:3 aspect ratio) or 1200x600px (2:1 aspect ratio)
- **Format:** JPG (for photos) or PNG (for graphics)
- **Quality:** 80-85% (good balance of quality and file size)
- **File Size:** Under 200KB per image (optimized)

### File Naming:
Use lowercase letters, hyphens, and numbers only. No spaces or special characters.

## 🛠️ Image Optimization Tips

1. **Use Image Optimization Tools:**
   - TinyPNG (https://tinypng.com/) - Compress images
   - Squoosh (https://squoosh.app/) - Advanced compression
   - ImageOptim - Desktop app for batch optimization

2. **Before Adding:**
   - Resize to recommended dimensions
   - Compress to reduce file size
   - Ensure good quality/readability
   - Test on different screen sizes

3. **Next.js Optimization:**
   - Images are automatically optimized by Next.js Image component
   - Supports WebP/AVIF formats
   - Responsive sizing handled automatically

## ✅ After Adding Images

1. Images will automatically appear on the blog page
2. If an image is missing, a default gradient placeholder will show
3. All images are lazy-loaded for performance
4. Images are responsive (adapt to screen size)

## 📝 Notes

- Images are optional - if you don't add a thumbnail, a beautiful gradient placeholder will be shown
- You can add images gradually - start with your most important posts
- Consider creating a consistent visual style across all thumbnails
- Use high-quality, relevant images that represent the content
