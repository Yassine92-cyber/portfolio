# How to Add Blog Thumbnail Images

## Quick Guide

1. **Place your images** in this folder: `public/images/blog-thumbnails/`

2. **Name your images** exactly as listed below (case-sensitive):

### Required Image Files:

- `finnish-learning.jpg` (or .png, .webp)
- `unicorn-startup.jpg`
- `building-opportunities.jpg`
- `linkedin-platform.jpg`
- `finnish-integration.jpg`
- `communities-finland.jpg`
- `volunteering-finland.jpg`
- `recruitment-events.jpg`
- `mentoring-programs.jpg`
- `research-tools.jpg`
- `startup-programs.jpg`
- `linkedin-ssi.jpg`
- `hive-helsinki.jpg`
- `suomen-mestari.jpg`
- `job-portals.jpg`
- `hidden-job-market.jpg`

## Image Specifications

- **Size**: 400x400px or 600x400px (recommended)
- **Format**: JPG, PNG, or WebP
- **File size**: Under 500KB for best performance
- **Quality**: High quality but web-optimized

## What Happens If Images Are Missing?

If an image file doesn't exist, you'll see a placeholder icon (📄) instead. The blog will still work perfectly - you just need to add the images to see the thumbnails.

## Testing

After adding images:
1. Save the image files in this folder
2. Refresh your browser
3. The images should appear automatically

No code changes needed - just add the files!
