# Logo Download Guide

Quick reference for downloading organization logos.

---

## Direct Download Links

### 1. Slush
- **Website:** https://slush.org
- **Press Kit:** https://slush.org/press (check for logo downloads)
- **Alternative:** Search "Slush logo PNG" on Google Images (filter by transparent)

### 2. Junction
- **Website:** https://junction.fi
- **Press/Media:** Check footer or contact page for media kit
- **Alternative:** Use browser dev tools to inspect logo on their homepage

### 3. Arctic15
- **Website:** https://arctic15.com
- **Media Kit:** Check their website footer or contact page
- **Alternative:** Right-click logo on their site → "Save image as"

### 4. University of Helsinki
- **Website:** https://helsinki.fi
- **Brand Guidelines:** https://www.helsinki.fi/en/university/brand-guidelines
- **Logo Download:** Usually available in brand guidelines section

### 5. City of Espoo
- **Website:** https://espoo.fi
- **Brand Assets:** Check their website for logo downloads
- **Alternative:** Contact their communications department

### 6. Haaga-Helia
- **Website:** https://haaga-helia.fi
- **Media Kit:** Check their website for press materials
- **Alternative:** Use browser dev tools to extract logo

### 7. Familia
- **Website:** Check their website
- **Contact:** May need to request logo directly
- **Alternative:** Use their website logo if publicly available

### 8. Think Africa
- **Website:** Check their website
- **Contact:** May need to request logo directly
- **Alternative:** Use their website logo if publicly available

## Quick Method: Browser Dev Tools

1. **Open organization website**
2. **Right-click on logo** → "Inspect"
3. **Find image source** in HTML
4. **Right-click image URL** → "Open in new tab"
5. **Save image** (Ctrl+S or Cmd+S)
6. **Rename** to match required filename

---

## Logo Requirements

- **Format:** PNG with transparent background
- **Size:** 200-300px width (maintain aspect ratio)
- **File Size:** <100KB (compress if needed)
- **Naming:** Exact filenames (case-sensitive):
  - `slush.png`
  - `junction.png`
  - `arctic15.png`
  - `helsinki.png`
  - `espoo.png`
  - `haaga-helia.png`
  - `familia.png`
  - `think-africa.png`

---

## Optimization Tools

- **TinyPNG:** https://tinypng.com (compress PNG)
- **Squoosh:** https://squoosh.app (compress & resize)
- **Remove.bg:** https://www.remove.bg (remove background if needed)

---

## Placement

Once downloaded and optimized:
1. Place all logos in `public/logos/` folder
2. Verify exact filenames match
3. Test on your site - logos should appear automatically

---

## Fallback

If you can't find a logo:
- The component will show the organization name in a styled box
- You can add it later
- Site will still work perfectly
